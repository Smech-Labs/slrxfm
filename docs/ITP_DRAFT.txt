SLRXFM is a clean-room, from-scratch reimplementation of the behavior
of XandrosFileManager, the proprietary file manager shipped with
Xandros Desktop 1.0 (2002). It is part of a broader
historical-preservation and software-recreation project for that
discontinued distribution.

No original Xandros code, decompiled or otherwise, appears anywhere in
the package's source. The upstream repository documents its clean-room
methodology in detail (docs/CLEAN_ROOM.md): what was analyzed (string/
symbol-table evidence plus one targeted decompiled function, confirmed
to be ordinary ELF startup code), what was deliberately left as an
open, documented ambiguity rather than guessed at, and the specific
evidence trail behind each module's scope.

The application provides:
  - A folder tree and file-detail listing (Qt6 QAbstractItemModel-based)
  - Copy/cut/paste/delete/rename
  - Move-to-trash/restore/empty-trash
  - Symlink creation
  - Browsing of local, SMB (libsmbclient), FTP (libcurl/MLSD), and
    WebDAV (libcurl/PROPFIND) locations through one unified interface
